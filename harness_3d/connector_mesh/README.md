# 连接器/卡扣形状弹窗（connector_mesh）

2026-11-15 建。拓扑查看器本身是轻量化数据：节点只剩一个点，看不到连接器、
卡扣的真实形状。本目录解决这个问题：把单个实体的 STP 转成轻量 JS 网格，
注入 3D 拓扑 HTML，点击节点时弹窗显示该实体的真实 3D 形状。

## 工作流

```
单个实体 STP ──step_to_js.py──▶ meshes/<节点名>.js ──inject_popup.py──▶ 带弹窗的 3D HTML
```

1. **转网格**：`python step_to_js.py <input.stp> meshes/<节点名>.js [deflection] [name]`
   - deflection：三角化精度，默认 0.1mm（实测 0.3/0.5mm 体积几乎不降，三角形数由小特征主导）。
   - name：网格内部名，**必须等于拓扑节点名 name_3d**；不给则沿用 STP 文件名。
   - 输出格式：`window.CONNECTOR_MESH = {name, bbox_center, bbox_size, positions, indices}`。
   - 坐标已中心化（减包围盒中心），避免大坐标丢精度；原始中心保存在 `bbox_center`。
2. **注入**：`python inject_popup.py <floor.html> <meshes_dir> <output.html>`
   - 扫描 meshes/ 下全部 `*.js`，按内部 name 建成注册表 `CONNECTOR_MESHES` 注入 HTML。
   - meshes/ 为空时注册表为空，点击任何节点都不弹窗（不报错）。

## 命名规则

- JS 文件名与内部 `name` 都必须等于拓扑节点名 `name_3d`（CATIA 实例全名，含下划线个数）。
- 弹窗按名匹配：点击节点时查 `CONNECTOR_MESHES[n.name]`，名字对不上就不会弹。
- 同名实体靠下划线个数区分，各自一份 JS，不要共用。

## 通用规则（2026-11-15 18:09 用户定）

- **只针对连接器和卡扣两种节点**（`n.type` 为 `connector` 或 `clamp`）；分支点、接头、悬空端不弹。
- **有网格则弹、无则不弹**：文件夹里有以节点名命名的 JS 就展示，没有就默认不展示、不报错。
- **代码通用**：不写死任何节点名、节点编号、连接器名；新增实体只需往 meshes/ 里加 JS 文件，
  不用改代码。

## 弹窗行为

- 点击连接器/卡扣节点：右下角弹出小窗口，显示该实体真实 3D 形状，可拖动旋转、滚轮缩放。
- 弹窗常驻：鼠标移出不消失；点击弹窗之外任意处（主画布其他位置、页面空白处）才关闭；
  点弹窗内、点有网格的节点不关；右上角 × 照常关闭。
- 切换到不同网格时复用 renderer/scene，dispose 旧 geometry 后重建并重新取景。

## 规则与教训（血的教训，别再犯）

1. **反向面必须翻转三角绕向**（2026-11-15 BMS 实测踩坑）：
   OCC 里约 1/4 的面是 `TopAbs_REVERSED`（BMS：1823 个面里 455 个），
   三角化取出的绕向是反的，法向朝内。Three.js 默认单面渲染，
   这些面直接看不见，整个模型满屏窟窿碎片。修复：反向面交换 b/c
   翻转绕向。验证方法：按坐标配边，闭合实体每条有向边都应有反向边
   配对（BMS 修复后 238443 条边 100.0% 成对，仅 7 条未配对）。
2. **弹窗材质用 DoubleSide 兜底**：即使绕向仍有漏网之鱼，模型也不会
   出现窟窿（代价是光照略有偏差，可接受）。
3. **弹窗常驻，点击外部关闭**（2026-11-15 用户定，替代第一版的
   “鼠标移出自动消失”）：鼠标移出不消失；点击弹窗之外任意处
   （主画布其他位置、页面空白处）才关闭；点弹窗内、点有网格的节点不关；
   右上角 × 照常能关。
4. **精度参数影响小**：BMS 实测 0.1mm 得 79498 三角形 / 66883 顶点 /
   JS 3.1MB；0.3mm / 0.5mm 仅降到 2.9 / 2.7MB——三角形数由小特征
   （针脚、筋位）主导，放粗精度省不了多少，默认就用 0.1mm。
